# Dashboard Business Intelligence untuk Analitik Kegiatan Akademik dan Alumni pada SMAN 4 Bangkalan

## Project Overview

Proyek skripsi yang mengembangkan dashboard Business Intelligence untuk mengolah, menganalisis, dan memvisualisasikan data akademik, ekstrakurikuler, dan alumni secara interaktif.

## Objectives

* Menyajikan informasi akademik dan alumni dalam bentuk dashboard interaktif.
* Mempermudah eksplorasi dan analisis data melalui visualisasi.
* Menyediakan informasi yang dapat mendukung pemantauan kondisi akademik dan alumni.

## Tools & Technologies

* Python
* Visual Studio Code
* SQLite
* ODBC
* Power BI

## Data Processing

Data diolah menggunakan Python dan disimpan dalam database SQLite sebelum dihubungkan dengan Power BI menggunakan ODBC untuk kebutuhan analisis dan visualisasi.

## Dashboard Pages

### 1. Beranda

Menampilkan ringkasan informasi utama dari data akademik, ekstrakurikuler, dan alumni.

### 2. Nilai Akademik

Menyajikan visualisasi dan analisis data nilai akademik siswa.

### 3. Ekstrakurikuler

Menyajikan informasi mengenai data dan partisipasi siswa dalam kegiatan ekstrakurikuler.

### 4. Tracer Alumni

Menyajikan informasi hasil tracer alumni untuk melihat kondisi dan perkembangan alumni.
